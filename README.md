# Elector

Χάρτες σταυρών προτίμησης και ποσοστών κομμάτων για τις ελληνικές εκλογές, ανά εκλογικό διαμέρισμα και ανά εκλογικό τμήμα.

Τα αποτελέσματα κατεβαίνουν από τον ιστότοπο αποτελεσμάτων του Υπουργείου Εσωτερικών, με ψήφους κομμάτων και σταυρούς ανά εκλογικό τμήμα. Κάθε τμήμα αντιστοιχίζεται σε κοινότητα της ΕΛΣΤΑΤ (απογραφή 2021). Κάθε χάρτης είναι ένα αυτόνομο HTML αρχείο με Leaflet και υπόβαθρο OpenStreetMap.

## Εκλογές

| Εκλογή | Κλειδί | Τι δείχνουν οι χάρτες |
|---|---|---|
| Βουλευτικές Ιουλίου 2019 | `2019` | σταυροί ανά υποψήφιο |
| Βουλευτικές Μαΐου 2023 | `2023/may` | σταυροί ανά υποψήφιο |
| Βουλευτικές Ιουνίου 2023 | `2023/june` | ποσοστό κόμματος επί των εγκύρων (δεν δημοσιεύτηκαν σταυροί ανά τμήμα) |
| Ευρωεκλογές 2024 | `2024/euro` | ποσοστό κόμματος επί των εγκύρων (δεν δημοσιεύτηκαν σταυροί ανά τμήμα) |

Οι χάρτες για το 2019 και τις ευρωεκλογές 2024 δεν είναι ακόμα στο `out/`.

## Απαιτήσεις

- Python 3.12. Όλα τα scripts χρησιμοποιούν μόνο τη standard library, εκτός από το `xlrd`.
- `xlrd`, μόνο για τα `stations_map.py` και `nikh_report.py`, που διαβάζουν το `.xls` των καταστημάτων ψηφοφορίας:

```
pip install xlrd
```

## Χρήση

1. Κατέβασε τα αποτελέσματα στο `data/stavroi.sqlite`. Η βάση δεν είναι στο repo και ξαναφτιάχνεται με αυτό το βήμα.

   ```
   python fetch.py 2023/may 45      # μία περιφέρεια (κωδικός ΥΠΕΣ)
   python fetch.py 2023/may all     # όλες οι περιφέρειες με έδρες, περίπου 22.000 τμήματα
   ```

   Αν το ξανατρέξεις, συνεχίζει από εκεί που σταμάτησε. Χρησιμοποιεί 4 παράλληλα αιτήματα, για να μη φορτώνει τον δημόσιο ιστότοπο.

2. Φτιάξε χάρτες ανά εκλογικό διαμέρισμα:

   ```
   python build.py 2023/may 45      # -> out/2023-may_45.html
   python build.py 2023/may all     # όλες οι περιφέρειες + out/index_2023-may.html (κάλυψη ανά νομό)
   ```

   Κάθε build ξαναγράφει το `out/index.html` και το `out/maps.json`.

3. Χάρτες ανά εκλογικό τμήμα, με σημεία στα καταστήματα ψηφοφορίας. Χρειάζεται το αρχείο του ΥΠΕΣ «Εκλογικά τμήματα με κατάστημα ψηφοφορίας» (`.xls`):

   ```
   python stations_map.py 2023/may 6 2 11 <venues.xls>              # σταυροί υποψηφίου 11 του κόμματος 2
   python stations_map.py 2023/may 31 131 0 <venues.xls> Πατρέων    # υποψήφιος 0 = ποσοστό κόμματος, προαιρετικά ένας δήμος
   ```

   Οι διευθύνσεις γεωκωδικοποιούνται με OpenStreetMap Nominatim, το πολύ ένα αίτημα το δευτερόλεπτο. Τα αποτελέσματα αποθηκεύονται στο `data/venues_geo.json`. Κρατιούνται μόνο όσα πέφτουν μέσα στη δημοτική ενότητα του τμήματος.

4. Αναφορά για τη ΝΙΚΗ στις 9 περιφέρειες όπου εξέλεξε βουλευτή:

   ```
   python -I -X utf8 nikh_report.py <venues.xls>
   ```

   Γράφει τα `out/NIKH_eklegmenoi_2023.html` και `exports/NIKH_2023_ana_dhm_enotita.csv`.

Στα Windows τρέξε τα scripts με `-X utf8`, για να τυπώνονται σωστά τα ελληνικά.

## Χάρτες

Άνοιξε το `out/index.html` σε browser. Στο πάνω μέρος κάθε χάρτη διαλέγεις κόμμα και υποψήφιο, και υπάρχει αναζήτηση υποψηφίου. Μπορείς να δεις ποσοστό ή απόλυτους αριθμούς, και απόκλιση από τον μέσο όρο της περιφέρειας. Από κάτω υπάρχει πίνακας περιοχών που ταξινομείται.

Μπορείς να στείλεις σύνδεσμο κατευθείαν σε έναν υποψήφιο: `out/2023-may_45.html#party=131&cand=8`.

## Αρχεία

| Αρχείο | Ρόλος |
|---|---|
| `fetch.py` | λήψη αποτελεσμάτων στη SQLite |
| `build.py` | αντιστοίχιση τμημάτων με κοινότητες ΕΛΣΤΑΤ, χάρτες ανά περιοχή, index |
| `stations_map.py` | χάρτες σημείων ανά εκλογικό τμήμα |
| `nikh_report.py` | αναφορά ΝΙΚΗ Μαΐου–Ιουνίου 2023 |
| `template.html`, `stations_template.html` | πρότυπα σελίδων. Το `build.py` ενσωματώνει μέσα τους τα `common.css`/`common.js` και τα δεδομένα |
| `data/koinotites_2021.json`, `data/dhm_enotites_2021.json`, `data/oikismoi_2021.csv` | όρια κοινοτήτων και δημοτικών ενοτήτων, και κατάλογος οικισμών ΕΛΣΤΑΤ 2021 |
| `out/` | οι χάρτες που έχουν παραχθεί |
| `exports/` | CSV ανά δημοτική ενότητα ή τμήμα |

## Ακρίβεια

- Τα αποτελέσματα του ιστότοπου είναι **ανεπίσημα**. Τα επίσημα εκδίδονται αργότερα από τα δικαστήρια.
- Η αντιστοίχιση εκλογικών διαμερισμάτων με κοινότητες γίνεται με βάση τα ονόματα, και ανά περιφέρεια καλύπτεται συνήθως πάνω από το 95% των σταυρών. Η κάλυψη ανά νομό φαίνεται στο `out/index_<εκλογή>.html`. Δεν μπαίνουν στον χάρτη τα ειδικά τμήματα και τα τμήματα ετεροδημοτών.
- Για τους αρχηγούς κομμάτων ο ιστότοπος δίνει μόνο σύνολο σταυρών ανά περιφέρεια. Γι' αυτό οι χάρτες τους σημειώνονται ως μερικοί.
- Σε αστικές δημοτικές ενότητες με μία μόνο κοινότητα (π.χ. Αθήνα), όλη η ενότητα εμφανίζεται ως μία περιοχή. Για περισσότερη λεπτομέρεια, χρησιμοποίησε τους χάρτες ανά τμήμα.
